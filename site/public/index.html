FOR CLAUDE CODE & CODEX · OPEN SOURCE

Read Qur’an
while your agent thinks.

Send a prompt and a quiet reader opens at the exact ayah you left, or float it as a small card beside your agent. When your agent needs you, it says so and Space takes you back. When the turn ends, your place is saved.

Install: let your agent do it

Claude Code

Paste this into Claude Code (terminal, or the Code tab in the Claude desktop app):

Install the Quran Turn plugin for me. In the terminal, run claude plugin marketplace add rzrizaldy/quran-turn and then claude plugin install quran-turn@quran-turn. When both succeed, tell me to restart Claude Code. If the claude command isn't available, tell me to type /plugin marketplace add rzrizaldy/quran-turn and then /plugin install quran-turn@quran-turn myself, one line at a time.
Or run the commands yourself
  1. /plugin marketplace add rzrizaldy/quran-turn
  2. /plugin install quran-turn@quran-turn

Type each line into Claude Code on its own, one at a time.

Codex

Paste this into Codex (CLI or the Codex app):

Install the Quran Turn plugin for me. In the terminal, run codex plugin marketplace add rzrizaldy/quran-turn and then codex plugin add quran-turn@quran-turn. When both succeed, tell me to restart Codex and approve Quran Turn's hooks when it asks.
Or run the commands yourself
  1. codex plugin marketplace add rzrizaldy/quran-turn
  2. codex plugin add quran-turn@quran-turn

Run each line in your terminal, then start codex and approve Quran Turn’s hooks once.

Needs Node.js 18+. No dependencies, no account.

01 · PROMPT

You hand off a task

The reader opens where you stopped, or anywhere you choose: a surah, juz, ayah or page.

02 · READ

Your agent works

Read at your pace. Every ayah you move is saved locally, instantly.

03 · NEEDS YOU

It asks permission

“Claude needs you” slides in. Press Space when you’re ready; your reading isn’t cut off.

04 · DONE

The turn ends

Your place is kept. One line records the ayat you read, nothing more.

Exact text, never touched

Tanzil’s verified Uthmani text ships byte-for-byte and is checked by SHA-256 before it renders. No model ever writes a letter of it.

Fully offline

Text, fonts and reader live on your machine. Turn off Wi-Fi and it keeps working.

Yours, in plain files

Your position and reading log are small JSON files in ~/.quran-turn. No account, no sync, no analytics.

Update

SET IT ONCE · CLAUDE CODE

Turn on auto-update

  1. Run /plugin
  2. Open Marketplaces → quran-turn
  3. Choose Enable auto-update

New versions then download in the background. Run /reload-plugins when Claude Code tells you, or they load next launch.

OR ASK YOUR AGENT

Paste one prompt

Update the Quran Turn plugin: run claude plugin marketplace update quran-turn and then claude plugin update quran-turn@quran-turn. When it says it updated, tell me to run /reload-plugins.

That’s all. On your next prompt, the reader swaps itself to the new version and an open reader window reloads on its own. Your place and reading log are never touched. Coming from v0.4.0 or earlier? Refresh the reader window once.
